# Software 2.0 (2017)

## Citation

Karpathy, A. "Software 2.0". Medium, 2017. https://karpathy.medium.com/software-2-0-a64152b37c35.

## One-line summary

Neural network weights compiled from data constitute a new kind of software stack, displacing hand-written code across a widening set of domains.

## Key claims

- Software 1.0 is code written by people in languages such as Python or C++; Software 2.0 is neural network weights compiled from data.
- The Software 2.0 stack is written in optimisation, not in instructions.
- Whole classes of problems prove easier to express as datasets and loss functions than as explicit programs.
- The transition runs domain by domain: vision, speech, translation, games, robotics, and beyond.
- Software 2.0 brings new tooling needs: dataset versioning, model debugging, deployment, and monitoring.
- The 2.0 stack is more uniform, more portable to hardware, and more agile than the 1.0 stack in mature domains.

## Excerpts

> Introduction: "Neural networks are not just another classifier, they represent the beginning of a fundamental shift in how we develop software."
> ~ Karpathy, "Software 2.0", Medium, 11 November 2017

> The Classical Stack: "Software 1.0 is what we're all familiar with -- it is written in languages such as Python, C++, etc."
> ~ Karpathy, "Software 2.0", Medium, 11 November 2017

> Software 2.0 Approach: "Instead, our approach is to specify some goal on the behavior of a desirable program ... and use the computational resources at our disposal to search this space for a program that works."
> ~ Karpathy, "Software 2.0", Medium, 11 November 2017

> Ongoing Transition: "A large portion of real-world problems have the property that it is significantly easier to collect the data than to explicitly write the program."
> ~ Karpathy, "Software 2.0", Medium, 11 November 2017

> Benefits: "A neural network is a better piece of code than anything you or I can come up with in a large fraction of valuable verticals."
> ~ Karpathy, "Software 2.0", Medium, 11 November 2017

> Limitations: "The 2.0 stack can fail in unintuitive and embarrassing ways ... by silently adopting biases in their training data."
> ~ Karpathy, "Software 2.0", Medium, 11 November 2017

## Reveals about tendency of thought

- Frames AI progress as a substrate change in the software industry, not a bolt-on feature.
- Treats datasets and loss functions as first-class engineering artefacts.
- Anticipates the LLM OS thesis by treating models as the centre of the stack.
