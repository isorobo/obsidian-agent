# Software Is Changing (Again)

## Citation

Karpathy, Andrej. "Software Is Changing (Again)". YC AI Startup School, San Francisco, June 2025. https://www.youtube.com/watch?v=LCEmiRjPEtQ.

## One-line summary

Karpathy proposes a "Software 3.0" era in which LLM prompts written in natural language constitute a third fundamental paradigm of software development.

## Key claims

- Software has passed through three paradigms: explicit code (1.0), trained neural weights (2.0), and natural-language LLM prompts (3.0).
- LLMs function as a new operating system layer; the ecosystem of closed providers (OpenAI, Anthropic) and open alternatives (Llama) mirrors historical computing patterns.
- LLMs are "stochastic simulations of people" with jagged intelligence - superhuman on some tasks, failing on trivially simple ones - plus anterograde amnesia between sessions.
- The near-term opportunity is "partial autonomy apps": tools like Cursor and Perplexity that pair an application-specific GUI with adjustable human oversight.
- Infrastructure must be rebuilt for agents: LLM-readable documentation, agent-accessible APIs replacing click-based interfaces.

## Reveals about tendency of thought

- Karpathy's three-paradigm frame extends his 2017 "Software 2.0" argument into a unified historical arc, showing his preference for structural analogies over incremental analysis.
- The emphasis on partial-autonomy apps rather than full agents reflects his bottom-up, engineering-first worldview: build the suit before the robot.
- Comparing current LLM infrastructure to 1960s computing infrastructure reveals how Karpathy reads technological transitions through historical precedent.
