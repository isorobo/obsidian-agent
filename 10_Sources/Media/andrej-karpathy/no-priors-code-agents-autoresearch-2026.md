# Andrej Karpathy on Code Agents, AutoResearch, and the Loopy Era of AI

## Citation

Karpathy, Andrej. "Code Agents, AutoResearch, and the Loopy Era of AI". No Priors, hosted by Sarah Guo, 20 March 2026. https://open.spotify.com/episode/3u1XHEsAuK1VXRr81RzQDV.

## One-line summary

Karpathy describes how autonomous coding agents have already displaced human typing in his own workflow and outlines AutoResearch, his project to close the loop on AI research without human bottlenecks.

## Key claims

- Since December 2025, Karpathy has not typed code himself; coding agents handle the implementation layer entirely.
- AutoResearch removes the human from the optimisation loop: the goal is to "maximise token throughput" with the agent executing the full research iteration cycle.
- Current models display simultaneous brilliance and naivety: "I simultaneously feel like I'm talking to an extremely brilliant PhD student and a 10-year-old."
- Model capability limits today mostly feel like "skill issues" on the part of the user - problems that better prompting and tooling resolve.
- Infrastructure for the "agentic web" - LLM-readable docs, agent-accessible APIs - is the bottleneck, not model capability.

## Reveals about tendency of thought

- Karpathy's willingness to remove himself from the coding loop entirely - and to document it publicly - signals that he treats agent capability as a genuine threshold crossed rather than a marketing claim.
- AutoResearch extends his "LLM OS" framing to research itself: the agent is now the developer, and Karpathy is the architect of the loop.
- The "skill issue" framing positions current limitations as a human-workflow problem rather than a model-capability ceiling, consistent with his bottom-up, engineering-optimism stance.
