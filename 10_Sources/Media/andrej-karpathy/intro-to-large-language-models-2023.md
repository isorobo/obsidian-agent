# Intro to Large Language Models (2023)

## Citation

Karpathy, A. "Intro to Large Language Models". YouTube, November 2023. https://www.youtube.com/watch?v=zjkBMFhNj_g.

## One-line summary

A one-hour public lecture explains how large language models are trained, what they can do, and where the active research frontiers lie.

## Key claims

- Pretraining compresses internet-scale text into a parametric model that predicts the next token.
- Supervised fine-tuning on curated assistant transcripts converts a base model into a helpful chat model.
- Reinforcement learning from human feedback aligns the model toward preferred behaviour.
- Tool use, retrieval, and multimodality extend the bare token predictor into a capable assistant.
- Security threats include prompt injection, data exfiltration, and jailbreaks; defences remain immature.
- The LLM OS frame organises the field's open problems around kernel, tools, and memory.
