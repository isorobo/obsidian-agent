# LLM OS (2023)

## Citation

Karpathy, A. "LLM OS". Public talks and Twitter long-form, November 2023. https://twitter.com/karpathy/status/1723140519554105733.

## One-line summary

Karpathy proposes a conceptual model in which the large language model functions as the kernel of a new operating system, with tools, memory, and peripherals attached around it.

## Key claims

- The large language model functions analogously to the kernel of an operating system.
- Tools such as code interpreters, browsers, and calculators play the role of system calls.
- Context windows act as the working memory of the LLM OS, with retrieval as paging from longer-term storage.
- Multimodal inputs and outputs play the role of peripherals.
- The LLM OS abstraction reframes chat as one application among many running on the model.
- The framing predicts a proliferation of LLM-native applications rather than chat as the terminal interface.

## Reveals about tendency of thought

- Reaches for systems-level analogies rather than benchmark-level comparisons.
- Treats the model as substrate, not as endpoint product.
- Anticipates the agent stack by separating kernel, tools, and memory.
