wiki-ai-thinkers

Primary sources from 15 AI researchers, founders, and policy thinkers - rendered as a queryable knowledge graph.

1 - Start the local server

The browser artefacts read this vault via the File System Access API. That API requires a real http://localhost origin, so a tiny local server is needed (Python 3 stdlib, no install).

Windows

Open this folder in File Explorer (press Win+E), then open .workspace/ and double-click serve.bat.

If you cloned with VS Code, Cursor, or another editor: their sidebars open .bat files in the editor pane and never execute them. Either right-click serve.bat → Reveal in File Explorer, or run .\serve.bat in the integrated terminal.

macOS / Linux

cd .workspace
./serve.sh

Any platform (manual)

python .workspace/serve.py

2 - Open the graph

Once the server prints wiki-vault server is running, your browser should open automatically. If it doesn't, click below:

Open graph.html →

Or jump straight to the positions matrix: http://localhost:8765/positions.html

3 - Connect the vault

Click Connect vault in the page, pick the folder this file lives in (the vault root), and grant view access when Chrome asks. The graph renders in a few seconds. The browser remembers the folder via IndexedDB, so subsequent visits one-click reconnect.
